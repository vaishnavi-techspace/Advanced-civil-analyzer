📌 Project Description
A GUI-based Civil Engineering Material Analysis System developed using Python and Tkinter. This application helps users evaluate construction materials like Concrete, Steel, Brick, and Cement by verifying their properties against standard safety ranges.

---

🚀 Features
✔️ Multiple material support (Concrete, Steel, Brick, Cement)  
✔️ Dynamic input fields  
✔️ Predefined engineering ranges  
✔️ Instant SAFE / NOT SAFE result  
✔️ Error handling for invalid inputs  
✔️ Simple and clean user interface  

---

🛠 Technologies Used
- Python  
- Tkinter
